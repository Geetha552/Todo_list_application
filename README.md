# Enhanced Todo List App

A simple Todo List web application built using HTML, CSS, and JavaScript.  
It allows users to store, search, mark complete, and delete tasks — with data saved in `localStorage`.

---

## 🚀 Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Search tasks in real-time
- Persist data using localStorage
- Each task stored as an object:
```json
{
  "id": 1234567890,
  "text": "Example Task",
  "completed": false
}
